# 67 — Production Observability Model

Existing runtime surfaces expose lifecycle state, next action, stalled reason, policy-gap classification, false-positive suppression, permit expiry, attestation freshness, restart attempts, duplicate reconciliation, CAS failure, completion verification, rollback, orphan cleanup, harness result, policy revision and loaded runtime hash. Poli/Mainy health endpoints and Logi/Repairman user-unit status provide liveness. No second dashboard stack or authority store was introduced.
