The `codex` available via npx is a static site code generator, not an
AI code review CLI. The adapter returns SKIPPED when no LLM auditor CLI
is available. To wire a real auditor, set:
  AIMS_CODEX_CLI_CMD=claude -p    (Claude Code CLI in non-interactive mode)
or
  AIMS_CODEX_CLI_CMD=<any-cli> that accepts a prompt string and returns JSON
